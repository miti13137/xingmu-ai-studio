# 星幕本機影片合成：開發測試版

這是尚未完成的開發測試版，與 GitHub Pages 上既有 V1、V2、V3 分開，不會自動讀取其他裝置的瀏覽器資料。它只把已準備好的鏡頭影片依序合成 MP4，可以燒入每鏡字幕和混入背景音樂；並不提供 AI 劇本、圖片、影片、配音或嘴型同步，不是全自動正式版。

## 測試環境與啟動

需要 Python 3.10 以上及可由命令列執行的 FFmpeg、ffprobe；FFmpeg 應支援 libx264、AAC 和 subtitles/libass。繁體中文字幕需要系統有中文字型。Windows 可在安裝好上述工具後執行專案根目錄的 `Start-Xingmu-Dev.bat`。服務只監聽啟動它的電腦的 127.0.0.1；GitHub Pages、其他電腦或手機不能直接呼叫此本機服務。

1. 啟動後瀏覽器會開啟本機頁面；若未開啟，使用命令視窗中顯示的網址。
2. 可匯入 V3 匯出的作品 JSON 以帶入分鏡文字。備份 JSON 不含媒體，請為每一鏡選擇對應影片；也可自行新增鏡頭。
3. 選擇比例、需要的背景音樂，按「開始合成 MP4」，完成後下載影片並實際播放確認。
4. 執行期間素材及結果只存在本機暫存目錄，結束程式後清除。請在結束前下載；備份原始素材。異常中止時，作業系統可能保留暫存檔。

## 限制

- 尚未在 Windows 與 iPhone Safari 實測，不保證相容性或效能。此本機版本無法直接在 iPhone 上執行。
- 每個素材上限 100 MB，最多 50 鏡；大的素材可能需要較多記憶體與硬碟空間。
- 影片按原檔時長接續，無轉場；字幕以整個鏡頭為顯示區間，並非語音辨識或逐句對時。圖片、旁白獨立音軌、輸出品質設定和跨裝置專案恢復尚未實作。
- 音樂以固定音量混合，並會循環至影片結束；請自行確認素材使用權。
- 目前不連接外部 AI 或計費服務。程式本身不會建立費用，電力、既有設備及其他軟體費用不包括在此敘述中。

## 已驗證

在 Linux 測試環境執行 `python3 -m unittest discover -s tests -v`，以合成測試影片及聲音測試 API 上傳、生成、下載、帶字幕及音樂、缺檔與避免覆寫；這不是《霓虹舊夢》驗收成品。真實瀏覽器操作、iOS 與 Windows 尚未驗證。
