# 星幕本機影片合成：開發測試版

這是尚未完成的開發測試版，與 GitHub Pages 上既有 V1、V2、V3 分開，不會自動讀取其他裝置的瀏覽器資料。它可選擇串接同一台電腦已安裝的本機 Ollama 模型來產生劇本與分鏡草稿，也能把已準備好的鏡頭影片依序合成 MP4、燒入字幕、混入每鏡配音及背景音樂；尚未提供從文字生成圖片或場景影片，配音與嘴型同步需使用本機工具，不是全自動正式版。

## 測試環境與啟動

需要 Python 3.10 以上及可由命令列執行的 FFmpeg、ffprobe；FFmpeg 應支援 libx264、AAC 和 subtitles/libass。繁體中文字幕需要系統有中文字型。Windows 可在安裝好上述工具後執行專案根目錄的 `Start-Xingmu-Dev.bat`。服務只監聽啟動它的電腦的 127.0.0.1；GitHub Pages、其他電腦或手機不能直接呼叫此本機服務。

1. 啟動後瀏覽器會開啟本機頁面；若未開啟，使用命令視窗中顯示的網址。
2. 可匯入 V3 匯出的作品 JSON 以帶入分鏡文字。備份 JSON 不含媒體，請為每一鏡選擇對應影片或場景圖片；也可自行新增鏡頭。每鏡可選擇已準備的配音檔及設定配音開始秒數，未選擇則沿用原影片音訊。
3. 選擇比例、需要的背景音樂，按「開始合成 MP4」，完成後下載影片並實際播放確認。
4. 可按「製作專案備份」並下載 ZIP；之後重新開啟本機工作台，選擇該 ZIP 並按「恢復備份」。備份包含所選影片或場景圖片（連同秒數與運鏡設定）、目前字幕、配音與音樂；若曾匯入 V3 作品 JSON 或 AI 文字草稿，也保存該作品的原始文字資料。
5. 執行期間素材及結果只存在本機暫存目錄，結束程式後清除。請在結束前下載影片及專案備份；備份原始素材。異常中止時，作業系統可能保留暫存檔。

## 本機 AI 文字生成（實驗功能）

需事先自行安裝並啟動 Ollama，且已有本機模型。按「查詢本機模型」後填入作品名稱與故事構想，再按生成。可下載與 V3 匯入格式相容的作品 JSON。程式只連線 127.0.0.1:11434，不自動下載模型，且拒絕清單或模型資訊中可辨識的雲端模型；請勿把本機 Ollama 設定成代理遠端付費服務。

目前只有模擬模型服務的介面測試，**尚未使用實際模型完成生成測試**；無法保證生成品質、速度、格式或硬體需求，不能當作功能已正式驗收。

## 限制

- 尚未在 Windows 與 iPhone Safari 實測，不保證相容性或效能。此本機版本無法直接在 iPhone 上執行。
- 每個素材上限 100 MB，最多 50 鏡；專案備份內素材合計上限 200 MB。大的素材可能需要較多記憶體與硬碟空間。
- 備份不會自動讀取 V3 的瀏覽器素材、角色照片或其他未選擇的檔案；仍需另行保留這些原始檔。備份內保留原始匯入作品文字及獨立的當前字幕，不會同步改寫原始作品的文字欄位。
- 影片按原檔時長接續，無轉場；有提供配音的鏡頭，字幕依整段配音開始與結束時間顯示；其他字幕以整個鏡頭為顯示區間，並非語音辨識或逐句對時。若配音超過鏡頭長度，將報錯而非自動截斷。輸出品質設定和跨裝置同步尚未實作。
- 音樂以固定音量混合，並會循環至影片結束；請自行確認素材使用權。
- 本程式只連線本機服務，沒有整合計費 API，並過濾可辨識的雲端模型；若本機服務被另行配置為遠端代理或其他軟體收費，需另行確認。程式本身不會建立費用，電力、既有設備及其他軟體費用不包括在此敘述中。

## 已驗證

在 Linux 測試環境執行 `python3 -m unittest discover -s tests -v`，以合成測試影片及聲音測試 API 上傳、生成、下載、帶字幕及音樂、備份與恢復、缺檔與避免覆寫；這不是《霓虹舊夢》驗收成品。真實瀏覽器操作、iOS 與 Windows 尚未驗證。

## 本機國語配音

Windows 上可在鏡頭輸入台詞，按「用本機國語語音生成配音」，然後直接試聽或合成。需要系統已安裝能由 Windows PowerShell 的 System.Speech 選取的國語桌面語音，優先選台灣國語。語音品質取決於 Windows 音色。音檔可以使用專案備份保存。這項功能的 HTTP 介面在 Linux 以測試 WAV 驗證，Windows 真實語音仍待實測。

## 場景圖片鏡頭

在鏡頭的「畫面素材」選擇「場景圖片」，匯入 JPG、PNG 或 WebP，再設定 1 至 120 秒與「固定畫面」或「緩慢推近」。圖片鏡頭可和影片鏡頭交錯使用，並套用同一套字幕、配音與背景音樂流程。推近是調整整張圖片的取景，角色演出及嘴型同步使用另外的圖片運鏡選項。

## 角色嘴型同步（實驗功能）

使用可正常執行的 [SadTalker](https://github.com/OpenTalker/SadTalker) 本機安裝及模型。啟動星幕之前，將 `XINGMU_SADTALKER_DIR` 設為含有 `inference.py` 及 `checkpoints` 的資料夾。需依 SadTalker 官方安裝說明放置 256 模型、全圖映射模型及人臉偵測、定位模型。工作台會在上傳素材前檢查這些模型檔，缺檔時會顯示檔名。若模型安裝在獨立 Python 環境，將 `XINGMU_SADTALKER_PYTHON` 設為該環境 Python 執行檔的完整路徑。星幕預設以 CPU 執行模型，一次處理一鏡。若獨立 Python 環境已安裝支援 CUDA 的 PyTorch，可設定 `XINGMU_SADTALKER_DEVICE=auto`，由 SadTalker 選擇裝置。每鏡推論上限預設 900 秒，可用 `XINGMU_SADTALKER_TIMEOUT_SECONDS` 設為 60 至 7200 秒。已安裝模型後，推論不需要 API 金鑰。

在鏡頭的「畫面素材」選擇「場景圖片」，提供單人清晰正面角色照。「圖片運鏡」選擇「角色嘴型同步」，再加入配音檔，或使用本機國語語音生成。配音必須能放入鏡頭時長與配音起始秒數。合成時使用原配音，並保留字幕和背景音樂。每個鏡頭處理一位角色，建議將多人對白剪成各自的單人鏡頭。

在 Linux CPU 上以 SadTalker 官方圖片與 0.64 秒中文音訊樣本跑完真實推論，輸出 30 格、540 × 960 的 H.264／AAC MP4，容器長度 1.24 秒。比對台詞區間的畫格，排除字幕區後仍有畫面差異。該環境產生 16 格約需 4 分鐘。嘴型逐字貼合度、實際 Windows 效能及《霓虹舊夢》角色鏡頭仍待驗收。

《霓虹舊夢》的驗收劇本與七鏡分鏡草稿在 [neon-dream.json](examples/neon-dream.json)，可從工作台匯入並開始配置鏡頭。
